One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters — an entry for the [Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369) bounty on make.fun.

## The line

> Neptune is now 'The Group Chat Ghost' because it takes 165 years to reply, and when it does, it's just blue ticks.

Neptune takes about 165 Earth years to complete one orbit, and it is famously blue — so a reply that takes 165 years and arrives as nothing but blue ticks earns the name.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library. It writes the single line to `/output/entry.txt` and is fully deterministic — running it twice produces byte-identical output.
